# 📊 Bootcamp Excel — Data Analyst

Bienvenue dans mon repository dédié à mon **Bootcamp Excel**, réalisé dans le cadre de ma formation en Data Analysis.

Ce bootcamp est un parcours pratique de **30 jours**, organisé en 3 sprints, avec une progression des fondamentaux vers l'analyse de données et les fonctionnalités avancées d'Excel.

L'objectif final est de savoir transformer des données brutes en **informations exploitables, analyses pertinentes et dashboards interactifs**.

---

## 🎯 Objectif

À travers ce bootcamp, je développe progressivement les compétences nécessaires pour utiliser Excel comme un véritable outil d'analyse de données.

Le parcours suit une logique de Data Analyst :

**Données brutes → Nettoyage → Transformation → Analyse → KPI → Visualisation → Dashboard → Décision**

---

# 🚀 Les 3 sprints

## 🟢 Sprint 1 — Fondamentaux
### Jours 1 à 10

Le premier sprint est consacré à la maîtrise des bases d'Excel.

### Compétences travaillées

- Prise en main d'Excel
- Organisation des données
- Références de cellules
- Formules et fonctions
- Fonctions conditionnelles
- Fonctions statistiques
- Calculs
- Manipulation des données
- Premières analyses
- Mise en forme des résultats

**Statut : ✅ Terminé**

---

## 🔵 Sprint 2 — Data Analysis
### Jours 11 à 20

Ce sprint est consacré à l'analyse de données sur des jeux de données plus réalistes.

L'objectif est de passer de la simple manipulation d'Excel à une véritable démarche d'analyse.

### Compétences travaillées

- Analyse de données
- Tableaux structurés
- Fonctions d'analyse
- Calcul de KPI
- Graphiques
- Tableaux croisés dynamiques (TCD)
- Segments
- Nettoyage des données
- Gestion des valeurs manquantes et incohérentes
- Importation de données
- Power Query
- Création de dashboards interactifs
- Interprétation des résultats

## 🟠 Sprint 3 — Advanced Excel
### Jours 21 à 30

Le dernier sprint sera consacré aux fonctionnalités avancées d'Excel.
